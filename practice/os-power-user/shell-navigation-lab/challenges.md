# Shell Navigation Challenges

Run `python setup_lab.py` first, then `cd lab/home/amina`. Solve every challenge in **PowerShell**
and in **Bash** (Git Bash, WSL, or a Linux VM). Answers are hidden below each one - try first.

Expected answers come from the lab as generated by `setup_lab.py` (it's seeded, so they match).

---

### 1. Where am I, what's here?

Print your current directory, then list everything in it **including hidden files**.

<details><summary>Answer</summary>

```powershell
Get-Location
Get-ChildItem -Force          # -Force shows hidden + system files
```

```bash
pwd
ls -la                        # -a shows dotfiles
```

You should see `.bashrc`, `.secret-notes.txt`, `.ssh/` - and on Windows, `desktop.ini` only appears
with `-Force` (it has the Windows *hidden* attribute; dotfiles are only "hidden" by Linux convention).

</details>

### 2. Find the treasure

Go into `a/b/c/d`, read `treasure.txt`, then return home in **one** command using a relative path.

<details><summary>Answer</summary>

```powershell
Set-Location a\b\c\d ; Get-Content treasure.txt ; Set-Location ..\..\..\..
```

```bash
cd a/b/c/d && cat treasure.txt && cd ../../../..     # or: cd - / cd ~ (if home were real)
```

</details>

### 4. How many errors?

How many lines in `logs/app.log` contain `ERROR`? Then count across **all** logs recursively.

<details><summary>Answer - 14 in app.log, 19 in old/app-2026-02.log</summary>

```powershell
(Select-String -Path logs\app.log -Pattern ERROR).Count
Get-ChildItem logs -Recurse -Filter *.log | Select-String ERROR | Group-Object Path | Select-Object Count, Name
```

```bash
grep -c ERROR logs/app.log
grep -rc ERROR logs
```

</details>

### 5. Only the interesting errors

Show only the `connection refused` errors from `logs/app.log` and save them to `refused.txt`.

<details><summary>Answer - 5 lines</summary>

```powershell
Select-String -Path logs\app.log -Pattern "connection refused" | ForEach-Object Line | Out-File refused.txt
```

```bash
grep "connection refused" logs/app.log > refused.txt
wc -l refused.txt
```

</details>

### 6. What's eating the disk?

List the 3 largest files under the home folder.

<details><summary>Answer - holiday-video.mp4 (6 MB), then the 7-Zip installers (1.5 MB each)</summary>

```powershell
Get-ChildItem -Recurse -File -Force | Sort-Object Length -Descending | Select-Object -First 3 FullName, Length
```

```bash
find . -type f -printf "%s %p\n" | sort -nr | head -3      # GNU find
du -ah . | sort -h | tail -4                               # alternative: human-readable
```

</details>

### 7. Old junk

Find files not modified in the last 180 days.

<details><summary>Answer - holiday-video.mp4 and the three setup-7zip installers</summary>

```powershell
Get-ChildItem -Recurse -File | Where-Object LastWriteTime -lt (Get-Date).AddDays(-180)
```

```bash
find . -type f -mtime +180
```

</details>

### 8. Duplicates

Delete the duplicate installers `setup-7zip (1).exe` and `setup-7zip (2).exe` but keep `setup-7zip.exe`.
**List first, delete second.**

<details><summary>Answer</summary>

```powershell
Get-ChildItem Downloads -Filter "setup-7zip (*).exe"            # check
Get-ChildItem Downloads -Filter "setup-7zip (*).exe" | Remove-Item -WhatIf   # dry run
Get-ChildItem Downloads -Filter "setup-7zip (*).exe" | Remove-Item
```

```bash
ls Downloads/setup-7zip\ \(*\).exe
rm -i Downloads/setup-7zip\ \(*\).exe      # -i asks before each delete
```

`-WhatIf` (PowerShell) and `rm -i` / `ls` first (Bash) are habits that save careers.

</details>

### 9. Spot the suspicious download

One file in Downloads uses a **double extension** trick common in malware. Find it with a pattern.

<details><summary>Answer - invoice_8841.pdf.exe</summary>

```powershell
Get-ChildItem Downloads -Filter *.exe | Where-Object Name -match '\.\w+\.exe$'
```

```bash
ls Downloads | grep -E '\.[a-z]+\.exe$'
```

Windows hides known extensions by default, so the user saw `invoice_8841.pdf`. Turn on
*File name extensions* in Explorer (View → Show) on every machine you support.

</details>

### 11. CSV filtering

From `Documents/Projects/vpn-rollout/users.csv`, list usernames in the Finance department.

<details><summary>Answer - tunde, sara</summary>

```powershell
Import-Csv Documents\Projects\vpn-rollout\users.csv | Where-Object dept -eq Finance | Select-Object -ExpandProperty username
```

```bash
grep Finance Documents/Projects/vpn-rollout/users.csv | cut -d, -f1
```

Notice PowerShell understands the CSV **columns** (objects), Bash just sees **text**.

</details>

### 12. Follow a log live

In one terminal, follow `logs/app.log`. In another, append a line and watch it appear.

<details><summary>Answer</summary>

```powershell
Get-Content logs\app.log -Wait -Tail 5
# other terminal:
Add-Content logs\app.log "2026-03-02 09:00:00 ERROR test: manual entry"
```

```bash
tail -f logs/app.log
# other terminal:
echo "2026-03-02 09:00:00 ERROR test: manual entry" >> logs/app.log
```

</details>

### 13. Errors and output to separate files

Run a command that lists both `Documents` and a folder that doesn't exist. Send normal output to
`ok.txt` and the error to `err.txt`.

<details><summary>Answer</summary>

```powershell
Get-ChildItem Documents, nope 1> ok.txt 2> err.txt
```

```bash

```

</details>

### 14. Bonus: one-liner report

Produce a count of log lines **per level** (INFO/WARN/ERROR) in `logs/app.log`.

<details><summary>Answer</summary>

```powershell
Get-Content logs\app.log | ForEach-Object { ($_ -split '\s+')[2] } | Group-Object | Select-Object Name, Count
```

```bash
awk '{print $3}' logs/app.log | sort | uniq -c
```

</details>
